# landslide_project
The Smart IoT-Based Landslide Detection and Early Warning System uses ESP32 and sensors to monitor soil moisture, rainfall, vibration, and tilt. It provides alerts through a buzzer, LCD, and traffic lights. A servo-controlled barrier and Blynk platform enable automated safety measures and remote monitoring.
The Smart IoT-Based Landslide Detection and Early Warning System is designed to monitor environmental conditions in landslide-prone areas. It uses an ESP32 microcontroller with soil moisture, rain, vibration and tilt sensors to detect potential landslide risks. When unusual conditions are detected, the system provides alerts through a buzzer, LCD and traffic light indicators. A servo motor controls the road barrier, while Wi-Fi and the Blynk platform enable remote monitoring.
